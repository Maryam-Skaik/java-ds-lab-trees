# ✅ Assignment Solutions – Binary Trees Module

This folder contains **model solutions** for Binary Trees assignments
in the Java DS Lab.

📌 Solutions are released **after the semester** for revision and self-study.

---

## 📚 Problems Covered

1️⃣ Count leaf nodes in a binary tree  
2️⃣ Swap children of every node (mirror tree)  
3️⃣ Print right view of a binary tree  
4️⃣ Sum of all left leaf nodes  
5️⃣ Check if two binary trees are identical  
6️⃣ Find maximum value in binary tree (bonus)

---

## 🎯 Learning Objectives

- Understand **tree traversal patterns** (pre-order, level-order)
- Apply **recursion** effectively on binary trees
- Solve problems using **structural properties of trees**
- Restore tree properties after operations where necessary

---

## ⚠️ Notes

- All problems use **recursive approaches** except right view (level-order)
- Edge cases to test:
  - Empty tree
  - Single-node tree
  - Balanced vs unbalanced tree
- Comments in code explain step-by-step logic for students
